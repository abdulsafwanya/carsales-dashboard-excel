# carsales dashboard analysis

## 1. Project Overview

- Developed an interactive Car Sales Dashboard using Microsoft Excel.
- Analyzed car data based on manufacturers, models, fuel types, mileage, and prices.
- Used PivotTables, PivotCharts, slicers, and KPI cards.
- Presented key insights through interactive visualizations.

## 2. Project Objectives

- Analyze car sales data using Excel.
- Compare car prices across manufacturers.
- Analyze mileage by fuel type.
- Identify manufacturing-year trends.
- Create an interactive dashboard using slicers.

## 3. Dataset Information

- **Manufacturer:** Ford, Toyota, VW, BMW, Porsche.
- **Model:** Fiesta, Mondeo, Golf, Prius, RAV4.
- **Engine Size:** Engine capacity in litres.
- **Fuel Type:** Petrol, Diesel, Hybrid.
- **Year of Manufacture:** Manufacturing year of each car.
- **Mileage:** Distance travelled by the car.
- **Price:** Listed price of the car.

## 4. Dashboard Features

- Total Cars KPI
- Average Mileage KPI
- Average Engine Size KPI
- Latest Manufacturing Year KPI
- Maximum Price KPI
- Maximum Mileage KPI
- Models by Manufacturer chart
- Average Price by Manufacturer chart
- Average Price by Fuel Type chart
- Average Mileage by Fuel Type chart
- Models by Year chart
- Average Price by Year chart
- Interactive Manufacturer, Fuel Type, and Year slicers
